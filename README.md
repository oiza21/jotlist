# Jotlist

A to-do list with notes, built entirely with AI for HNG Internship 15, Stage 1.

## Features

- Create, view, edit and delete tasks
- Notes on every task (add while creating, or later)
- Priorities: high, medium, low
- Due dates with overdue warnings
- Search across tasks and notes
- Filter by status (all, to do, done, overdue) and priority
- Sort by newest, due date or priority
- Progress bar and "clear completed"
- Dark mode
- Data is saved in your browser, so it stays after a reload

## Run locally

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```

## Deploy

Import this repository in Vercel. It detects Vite automatically (build command `npm run build`, output `dist`).
